# Sistema da Academia

Sistema simples para gerenciar alunos de uma academia, feito em Python.
Projeto de estudo, em desenvolvimento.

## O que ele faz

- Cadastra alunos (nome, idade, peso e altura)
- Calcula o IMC e mostra a classificação
- Lista todos os alunos cadastrados
- Consulta alunos pelo nome

## Tecnologias

- Python
- CustomTkinter (interface)
- SQLite3 (banco de dados)

## Estrutura

- `interface.py`: telas do sistema
- `index.py`: back-end e banco de dados

## Como usar

**Opção 1: executável (Windows)**
Baixe o `sistema_academia.exe` na aba **Releases** e dê dois cliques.
